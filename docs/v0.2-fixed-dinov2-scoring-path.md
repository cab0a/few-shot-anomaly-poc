## Implemented Fixed Path

The implementation in [`dinov2_scoring.py`](../src/few_shot_anomaly_poc/dinov2_scoring.py) accepts only the preregistered candidate:

1. require one contiguous `512 x 512 x 3` RGB `uint8` NumPy array;
2. convert it to a CPU float32 NCHW tensor in `[0, 1]`;
3. resize to `224 x 224` or `448 x 448` with bicubic interpolation, `align_corners=False`, and antialiasing;
4. apply ImageNet mean and standard-deviation normalization;
5. request one normalized final layer through `get_intermediate_layers` with no reshape or class-token return;
6. L2-normalize each 384-dimensional patch vector with epsilon `1e-12`;
7. calculate exact cosine distance, clamped to `[0, 2]`;
8. search the memory bank in deterministic blocks of 2,048 reference patches; and
9. sort patch distances descending and average `max(1, floor(0.01 * patch_count))`.

This gives 256 query patches and a top count of 2 at `224`, and 1,024 query patches and a top count of 10 at `448`.

The production memory-bank constructor requires exactly 20 reference images. It rejects an unsupported count rather than silently changing the reference budget. The implementation does not add FAISS, approximate search, masking, augmentation, projection, quantization, compilation, half precision, GPU execution, or pixel-level output.

## Stable Rejection Boundary

The scoring primitive uses stable failure codes for:

- unsupported resolution;
- wrong image object, shape, dtype, or contiguity;
- unavailable isolated PyTorch runtime;
- invalid model state;
- preprocessing or feature-extraction failure;
- unexpected patch-token shape;
- non-finite or non-unit feature vectors;
- a reference count other than 20;
- invalid memory-bank metadata, shape, dtype, or device;
- distance-computation failure or an invalid distance range; and
- a non-finite or out-of-range scalar score.

Validation occurs before an invalid input can become a numeric anomaly score. Threshold selection and classification remain outside this primitive.

## Bounded Synthetic Smoke

The successful run used the fixed source, checkpoint, dependency environment, execution commit, four PyTorch intra-op threads, one inter-op thread, deterministic algorithms, disabled xFormers, blocked socket operations, and CPU float32 tensors.

The smoke generator created one deterministic reference RGB array and one deterministic query RGB array from fixed coordinate formulas. It did not use the preregistered PCG64 timing workload. To exercise the required memory-bank shape without performing the future fitting workload, the runner repeated the one synthetic reference embedding 20 times. The artifact identifies this explicitly.

| Resolution | Query patches | Memory patches | Top patches | Synthetic scalar score | Independent NumPy scalar difference |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 224 | 256 | 5,120 | 2 | `0.4834079146` | `5.9604645e-08` |
| 448 | 1,024 | 20,480 | 10 | `0.1085124612` | `8.1956387e-08` |

Both scalar differences are below the unchanged `1e-6` score tolerance. The maximum patchwise differences between the blocked PyTorch and full NumPy calculations were `7.7486038e-07` and `1.1920929e-06`. Patchwise cross-library equality is recorded as a non-gating diagnostic because the preregistration defines the `1e-6` reproducibility condition for final scalar scores, not individual patch distances.

The displayed synthetic scores are not anomaly metrics. Their relative magnitude does not show that one resolution is more accurate, faster, or preferable.

## Decision

### Result: `PROCEED TO PREREGISTERED CPU TIMING WORKLOAD`

The implementation gate passes because:

1. both fixed resolutions complete the decoded-RGB-to-scalar-score path;
2. patch counts, embedding dimension, memory-bank shape, and top counts match the preregistration;
3. every feature, distance, and score is finite;
4. the exact blocked search passes direct tensor tests;
5. each smoke scalar agrees with an independent NumPy calculation within `1e-6`;
6. local source, checkpoint, strict-load, dependency, thread, network, and xFormers boundaries remain verified; and
7. the committed artifact and its SHA-256 are locked by tests.

This result authorizes only the preregistered synthetic CPU timing workload. It does not select a resolution, pass the one-second p95 gate, authorize VisA evaluation, or adopt DINOv2.
