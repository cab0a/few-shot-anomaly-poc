## Interpretation

This result establishes only that the formal workload was not permitted to run on the observed machine state. It is not evidence that DINOv2 is slow, fast, accurate, inaccurate, suitable, or unsuitable. It does not supersede the preceding fixed scoring-path smoke result, and it does not change the v0.1 `REJECT` decision.

The one-second p95 gate, 25 untimed warm-ups, 300 measured invocations per resolution, `224`-then-`448` process order, and offline score-reproducibility check remain unchanged and untested.

## Retry Rule

A retry is allowed only if the observed environment meets the unchanged minimum of `4,045,017,088` RAM bytes and every earlier condition still passes. The required value, measurement method, ordered conditions, candidate settings, workload counts, and gates must not be changed to obtain a pass.

Changing the host WSL memory allocation or restarting WSL is an external machine-state operation and was not performed by this milestone. After any separately authorized environment correction, the same precondition checker must run first from a new clean execution commit. The timing workload must remain unstarted if any ordered precondition fails.
