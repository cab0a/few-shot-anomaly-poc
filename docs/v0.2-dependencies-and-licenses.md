# v0.2 Isolated Dependency Lock and Preliminary License Inventory

## 日本語概要

本書は、DINOv2 CPU preflight専用の分離環境について、CPython 3.13.14、CPU版PyTorch、直接・推移依存17件を固定したmetadata-only lockと、各配布物の予備license inventoryを記録します。CUDA系、optional extra、source buildは対象外であり、package、DINOv2 source、checkpoint、評価dataは取得・インストールしていません。

全配布物に公開hashと確認可能なlicense情報がありますが、wheel内部のlicense fileとbundled third-party noticeは未確認です。したがって次工程は、固定wheelを実行せずに取得してhashと内部noticeを検査する段階に限定します。詳細は以下の英語本文を参照してください。

## English Summary

This record fixes a separate metadata-only dependency resolution for the preregistered DINOv2 CPU preflight and inventories the published license evidence for all 17 resolved third-party distributions. The lock admits only the fixed CPython, Linux x86-64, CPU-PyTorch path and forbids source builds. It authorizes controlled acquisition of the locked wheel artifacts for checksum and internal-license inspection only; it does not authorize installation, model acquisition, execution, benchmarking, or dataset access.

## Isolation and Resolution Controls

The v0.2 definition is separate from the frozen v0.1 root environment. It fixes:

- `requires-python = "==3.13.14"`;
- NumPy `2.5.1`;
- PyTorch `2.13.0+cpu` from an explicit PyTorch CPU index;
- pytest `9.1.1` and Ruff `0.16.0` in the development group;
- uv `0.11.32`;
- a Linux x86-64 resolution marker and required environment;
- prerelease rejection;
- project packaging disabled; and
- source builds disabled.

The resolution does not select CUDA, ROCm, XPU, a nightly build, a prerelease, or an optional PyTorch extra. It does not add `torchvision`, FAISS, `xformers`, OpenCV, Pillow, scikit-learn, or AnomalyDINO.

The lock contains source-distribution metadata because the registry exposes it, but `no-build = true` prevents a source distribution from satisfying this environment. Some binary projects have both manylinux and musllinux candidates in the cross-platform lock. The preregistered WSL2 glibc machine selects the manylinux artifact listed below; a musl environment is not an approved benchmark machine.

## Next Authorized Milestone

The next milestone is **controlled dependency artifact acquisition and internal license inspection**. It may:

1. download only the expected wheels into a unique ignored staging directory outside Git;
2. verify every byte stream against the locked SHA-256 before inspection;
3. reject archives with unsafe paths, links, duplicate members, or unexpected file types;
4. inspect archives without importing or executing package code;
5. inventory and hash each `dist-info` license file and bundled third-party notice;
6. identify native shared objects and their accompanying notices; and
7. commit a completed inventory and an install/no-install decision.

It must not install packages, acquire DINOv2 source or weights, access VisA, run a CPU benchmark, or implement anomaly scoring. Any hash mismatch, missing controlling license, unreviewable bundled notice, wrong-platform artifact, or need for a source build is a stop condition.
