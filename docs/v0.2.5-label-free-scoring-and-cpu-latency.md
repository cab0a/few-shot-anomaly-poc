# v0.2.5 Label-Free Final-Test Scoring and CPU Latency

## 日本語概要

この文書は、VisA `pcb2`のfinal-test 200枚をsemantic pathやlabelを含まないopaque asset IDだけで3方式に入力し、固定score・固定thresholdによる分類・CPU latencyを保存した`v0.2.5`の実行記録です。各方式で200 score、200 classification、600 latency observationを生成し、score failureと3 pass間のscore差は0件でした。CPU p95はECC残差法663.9 ms、Patch HOG + One-Class SVM 545.0 ms、DINOv2 224 461.1 msでした。labelは未開示のため、この段階ではFPR、recall、AUROC、AUPRC、FP/FN、採用判断を計算していません。詳細は以下の英語本文に記載します。

## English Summary

The v0.2.5 stage scored all 200 opaque final-test assets with the three frozen methods and recorded the preregistered CPU workload without accessing labels, semantic source paths, the official split, the HMAC key, or the sealed mapping. Each method produced 200 canonical scores, 200 fixed-threshold classifications, and 600 timed observations. No score failed, and every repeated score matched its canonical value exactly.

## Fixed Boundary

The root runner received only:

- the 200-record opaque scoring manifest with asset IDs `asset-000000` through `asset-000199`;
- byte-verified opaque JPEG assets;
- the three fitted-state files whose hashes were fixed by v0.2.4;
- the three fixed normal-only thresholds;
- the frozen v0.2 config and artifact schema; and
- the pushed execution commit identity.

The isolated DINOv2 worker received an ignored RGB memory map, opaque asset IDs, adapter durations, the hash-verified fitted state, the numeric threshold, and fixed model/runtime assets. Its command contained no boundary-state path, label source, semantic source path, official split, HMAC key, or sealed mapping path. Network access remained blocked.

The run did not calculate image-level metrics, inspect score-ranked images, select failure cases, apply the complete hard-gate sequence, or produce an adoption decision.

## Preregistered Workload

Each method ran one full-sequence warm-up followed by three full timed passes over the same 200 opaque assets in ascending asset-ID order. Timed pass `0` supplied the canonical score. Status and failure code had to match across all timed passes, and repeated scores had to remain within absolute tolerance `1e-6`. No retry or outlier removal was permitted.

For ECC residual and Patch HOG + One-Class SVM, the timed boundary began with a decoded grayscale `uint8` image and included method preprocessing and scoring. For DINOv2, each total duration equals the separately timed decoded-BGR adapter plus the isolated RGB512-to-score duration. File reads, encoded-image decoding, fitted-state and model loading, fitting, interprocess transfer, and artifact writing were excluded.

Median latency uses the arithmetic mean of the middle pair over all 600 observations. P95 uses nearest rank `ceil(0.95 × 600) = 570`. Failed-score timings would remain included, although no score failed.

The DINOv2 median adapter duration was `6.789 ms`, and its median isolated scorer duration was `380.956 ms`. Total duration is calculated per observation before the total median and p95 are derived; component medians are not added to reconstruct the total median.

All three observed p95 values are below the preregistered `1.0 s/image` latency ceiling on the fixed machine. This is latency evidence only. The formal hard-gate trace and decision remain deferred because the earlier final-test FPR and anomaly-recall gates require the unrevealed labels.

The predicted-anomalous counts cannot be interpreted as true positives, false positives, anomaly prevalence, or comparative accuracy. The three methods use different score scales and thresholds, so the counts do not form a ranking of method quality.

- physical/logical cores: `4 / 8`;

## Known Limitations

- The results cover one category, one fixed reference set, one final-test order, one machine, and one execution.
- No confidence interval or repeated-run latency uncertainty is claimed.
- WSL2 scheduling and the recorded thread settings limit latency portability.
- Label-free predicted counts do not measure correctness or class separation.
- No image content was displayed or manually inspected, so no visual cause is assigned to any score.
- The execution source remains later than the v0.2.3 freeze source; this explicit process limitation must be addressed by the reproduction checkpoint rather than hidden.
- No localization or pixel-level evaluation is included.
