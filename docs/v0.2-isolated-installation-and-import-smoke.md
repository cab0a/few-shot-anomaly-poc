## Installation Sequence

### Stopped `uv sync` attempt

The first command used:

- the committed lock;
- `--locked`;
- `--offline`;
- `--no-index`;
- the verified local directory through `--find-links`;
- `--no-cache`;
- `--no-build`; and
- automatic Python downloads disabled.

uv created the target virtual environment, then stopped before package installation. The project maps PyTorch to an explicit CPU index in `tool.uv.sources`; with registry indexes disabled, uv did not substitute the local flat-index PyTorch wheel for that explicit source during locked synchronization.

The stop was retained as evidence rather than hidden. The new environment contained zero distributions after the failure. The lock and `pyproject.toml` were not relaxed or modified.

### Completed exact-wheel installation

The empty environment was populated using:

- `uv pip install`;
- the same uv `0.11.32`;
- the exact 17 local wheel paths already verified against the lock;
- `--offline`;
- `--no-index`;
- `--no-cache`;
- `--no-build`; and
- `--no-deps`.

This path did not perform dependency discovery or retrieve another artifact. It installed the supplied wheel files only. A subsequent offline `uv pip check` examined all 17 installed distributions and reported that all requirements were compatible.

## Reproducibility

With the verified uv `0.11.32` executable available as `${uv_bin}` and the inspected wheel set retained under the ignored local directory:

```bash
wheel_dir="data/external/v0.2/dependency-wheels/28a0878f3425bf6e"

"${uv_bin}" venv \
  environments/v0.2-preflight/.venv \
  --python .venv/bin/python \
  --no-python-downloads \
  --offline \
  --no-cache

"${uv_bin}" pip install \
  --python environments/v0.2-preflight/.venv/bin/python \
  --offline \
  --no-cache \
  --no-index \
  --no-deps \
  --no-build \
  "${wheel_dir}"/*.whl

"${uv_bin}" pip check \
  --python environments/v0.2-preflight/.venv/bin/python \
  --offline \
  --no-cache
```

Regenerate the deterministic smoke record outside the repository and compare it:

```bash
smoke_root="$(mktemp -d)"
PYTHONNOUSERSITE=1 PYTHONDONTWRITEBYTECODE=1 \
  environments/v0.2-preflight/.venv/bin/python -I -B \
  scripts/verify_v0_2_import_environment.py \
  --inspection-record artifacts/v0.2/dependencies/wheel-inspection.json \

cmp \
```
